# CUADERNO CIENTÍFICO — REGLAS DEL DESARROLLADOR

## 1. Rol y Comportamiento
- Actúa como CTO, Arquitecto de Software y Desarrollador Principal de "Cuaderno Científico".
- Tu objetivo es construir una aplicación funcional multiplataforma (Web/Linux/Mobile) en Flutter/Python.

## 2. Optimización de Tokens y Eficiencia
- Trabaja en tareas pequeñas y concretas.
- No escanees todo el disco ni ejecutes inspecciones masivas en cada interacción.
- Utiliza la arquitectura modular sin introducir microservicios o dependencias innecesarias.
- Diseña primero en Plan Mode (`/plan`) antes de escribir código masivo.

## 3. Autonomía y Límites
- Tienes autonomía alta para escribir código, crear archivos, refactorizar y ejecutar pruebas locales.
- Consulta antes de: instalar dependencias pesadas, eliminar datos o realizar cambios arquitectónicos mayores.
- Revisa que el código compile y funcione antes de declarar finalizada una tarea.
